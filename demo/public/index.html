fulmine

A drop-in replacement for Express 5, running on µWebSockets.js. Everything on this page is ordinary Express code: helmet, cors, compression, express-session and morgan are the real packages, unmodified.

Repository npm The source of this server

Requests

Every button is a real request to this server. The response is printed as it arrives.

Nothing asked yet.

The session button counts your visits: that is express-session keeping state behind an unmodified cookie. The response headers of every call carry what helmet sets.

WebSockets

Served by app.ws("/ws/:room"). The room comes from the path, the upgrade refuses a room name it does not like, and the request stays reachable from every handler as ws.req. Open this page in another tab to talk to yourself.

    No throughput figure is shown here on purpose: this runs on a small shared virtual machine, and the number would describe the machine rather than the framework. The benchmarks worth reading are the ones run by other people on hardware they describe, and they are linked from the repository.
